# Silent Camera (무음 카메라)

**Silent Camera**는 도서관, 독서실 등 조용한 공간에서 매너 있게 사용할 수 있는 무음 카메라 웹앱(PWA)입니다.
앱 설치 없이 웹 브라우저에서 바로 실행할 수 있으며, 촬영부터 저장까지 모든 과정이 빠르고 간결하게 이루어집니다.

---

## 주요 기능
- **무음 촬영**: 소리 없이 사진을 촬영할 수 있는 직관적인 UI 제공
- **카메라 제어**: 전/후면 카메라 전환 빛 0.5x ~ 3x 줌 지원 (지원 기기에 한해 하드웨어 줌 적용)
- **촬영 도구**: 사진 구도를 돕는 그리드(격자) 토글
- **즉시 확인 및 보관**: 촬영 직후 사진 미리보기 및 기기 저장/공유 
- **오프라인 지원**: 서비스 워커(Service Worker) 캐싱을 통해 오프라인 환경에서도 앱 실행 가능

## 개인정보 및 보안
- **서버 전송 없음**: 촬영된 사진은 외부 서버나 네트워크로 절대 전송되지 않습니다.
- **로컬 처리**: 사진 촬영과 파일 생성 등 모든 처리는 사용자의 기기 내부에서만 안전하게 이루어집니다.
- **명시적 권한**: 사용자가 직접 '저장'이나 '공유'를 선택했을 때만 파일이 외부(기기 내 다른 앱)로 전달됩니다.

## 사용 방법
스마트폰 브라우저에서 **[camera.maieutic.kr](https://camera.maieutic.kr)** 에 접속하여 바로 사용할 수 있습니다.

## 기기에 앱처럼 설치하기 (PWA)
이 서비스는 별도의 앱 스토어를 거치지 않고도 기기 홈 화면에 추가해 **일반 앱처럼 전체 화면으로 사용**할 수 있습니다 (Progressive Web App).

**iOS (iPhone / iPad)**
1. **Safari** 브라우저에서 사이트에 접속합니다.
2. 화면 우측 하단의 **... 버튼**을 누릅니다.
3. 상단의 **공유 버튼(네모 안에서 위로 향하는 화살표)**을 누릅니다.
4. 나타나는 메뉴를 살짝 위로 올려 **'홈 화면에 추가'**를 선택합니다.
5. 우측 상단의 **'추가'**를 누르면 바탕화면에 앱 아이콘이 생성됩니다.

**Android (Galaxy 등)**
1. **Chrome** 브라우저에서 사이트에 접속합니다.
2. 주소창 우측의 **메뉴 버튼(⋮ 기호)**을 누릅니다.
3. **'홈 화면에 추가'** 또는 **'앱 설치'**를 선택합니다.
4. 안내 팝업에 따라 진행하면 바탕화면에 앱 아이콘이 생성됩니다.

## 프로젝트 구조
- `index.html`: UI 화면 및 카메라 동작 로직이 모두 포함된 단일 파일
- `manifest.json`: PWA 설치 및 디자인 설정을 위한 메타데이터
- `sw.js`: 오프라인 구동을 지원하는 서비스 워커 캐싱 로직
